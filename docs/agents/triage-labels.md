# Etiquetas de clasificación

| Rol de la skill | Etiqueta del repositorio | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Requiere evaluación de la persona responsable |
| needs-info | needs-info | Espera información de quien abrió la incidencia |
| ready-for-agent | ready-for-agent | Está suficientemente especificada para un agente |
| ready-for-human | ready-for-human | Requiere implementación humana |
| wontfix | wontfix | Se ha decidido no realizarla |

Usa esta correspondencia cuando una skill mencione un rol de clasificación.
Conserva las etiquetas existentes y crea únicamente las que falten.
